# Dotfiles role

This role clones a pinned commit of `matheuseabra/dotfiles` as `dev` and stows only portable packages (`btop`, `druk`, and `starship` by default). It intentionally does not deploy the macOS `zsh`, Ghostty, Herdr, OpenCode, Karabiner, skhd, Cava, wallpaper, or Keychain configuration.
